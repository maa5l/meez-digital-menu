# قائمة — منيو رقمي

منصة منيو رقمي تفاعلي للمطاعم والمقاهي (React + Vite + TypeScript).

## التشغيل

```bash
cp .env.example .env.local
npm install
npm run dev
```

## أوامر

| الأمر | الوصف |
|-------|--------|
| `npm run dev` | خادم التطوير |
| `npm run build` | بناء الإنتاج |
| `npm run lint` | فحص الكود |
| `npm run test` | الاختبارات |
